# 弈境五子棋 · AI 对弈平台 (Gomoku Web)

精美典雅的东方现代风格五子棋网页版，支持与本地多等级智能算法或云端大语言模型（DeepSeek、Gemini、OpenAI、通义千问等）实时对弈。

---

## ✨ 核心特性

1. **🚀 100% 免费部署于 Cloudflare**
   - 纯前端零后端依赖架构，原生适配 **Cloudflare Pages**（无限流量、全球 CDN 加速、自带免费 HTTPS）。
   - 随附 `functions/api/proxy.js` 无服务器反向代理，解决部分国内大模型 API 跨域问题。
2. **🤖 多大模型自定义配置**
   - 支持主流大模型服务商预设：**DeepSeek**、**Google Gemini**、**OpenAI**、**阿里通义千问 (DashScope)**、**月之暗面 (Kimi)** 以及 **本地 Ollama / OneAPI / 自定义兼容端点**。
   - **流式思考 + 超时兜底**：落子采用 SSE 流式输出，状态栏实时显示思考计时与接收字数，AI 气泡同步滚动显示输出片段；45 秒收不到数据或超过 180 秒总上限时自动改由本地引擎代下，不会把棋盘锁死。推理型模型（`deepseek-reasoner` / `gemini-2.5-pro` / 带 thinking 的 qwen）已做参数适配。
   - 具有 4 种生动的 AI 对话人设性格（**幽默话痨**、**世外高人**、**傲娇对手**、**严谨冷静**），边下棋边对话吐槽！
   - 支持直观的“测试模型连接”按键与 API 密钥本地安全加密存储。
3. **📊 输赢战绩与历史保存**
   - 自动持久化保存总局数、胜局、败局、综合胜率、连胜记录于本地 `localStorage`。
   - 详细历史对局流水账（对战时间、执棋先后手、对手模型与难度、步数、用时）。
4. **⚔️ 四档对战难度可调**
   - **入门低难度 (Novice)**：基础威胁识别与适当随机性，适合轻松休闲。
   - **业余中难度 (Intermediate)**：攻防兼备，敏锐捕捉冲四、活三威胁。
   - **大师高难度 (Master)**：Alpha-Beta 剪枝深度极小化极大搜索，步步为营。
   - **职业级 (Pro)**：新增第四档，比大师强一个量级——
     - *棋形识别升级*：改用「5 格窗口 + 成五点计数」判定，能正确识别跳三 `X_XX`、跳四 `XX_XX` 这类旧版连续计数漏掉的形状；活三/眠三按「落子后能否成活四」的递归定义判定，与禁手规则口径一致。
     - *VCF 强制杀搜索*：穷举己方连续冲四分支，对手只有唯一防守解，因此能算出「连续冲四取胜」「四四 double 杀」这类固定深度看不到的杀招。
     - *迭代加深 + 置换表 + 时间预算*：每步约 1.5 秒，在预算内尽量算得更深（实测中局可达 4~6 层）。
     - *Web Worker 后台搜索*：思考期间页面不卡，仍可翻看棋谱、回放、打开设置。
     - 自对弈验证：职业级对大师级执黑 3/3 胜（平均 15 手内结束）、执白 3/3 胜。
5. **⚖️ 先手禁手规则（三三 / 四四 / 长连）与贴心辅助**
   - **规则限制**：严格遵循连珠规则，先手黑棋不可下“三三禁手”（同时形成两个及以上活三）与“四四禁手”（同时形成两个及以上四），连子超过五颗为“长连禁手”。违规落子时伴随声音与提示阻止，两项规则可在设置中分别开关。
   - **四三不算禁手**：一子同时形成一个“四”和一个“活三”（四三杀）是黑棋唯一合法的取胜手段。判定时遵循方向优先级 **五 > 四 > 三** —— 某方向已成“四”就不再重复计入活三，避免把四三杀误判成三三禁手。
   - **悔棋按键**：一键撤销双方最近一轮走步，随时调整棋路。
   - **赢局高光提示**：五连成线金色光环特效与结算奖杯弹窗。
   - **原生音频合成**：内置 Web Audio API 拟真玉石落子声、胜利和弦、警告蜂鸣。
6. **📜 落子轨迹回放与逐手 AI 分析**
   - **落子轨迹面板**：每一手的序号、黑白、坐标、落子归属（你/AI）与单手用时自动成表，点击任意一手即跳回当时的盘面，最近八手以金色轨迹连线呈现在棋盘上。
   - **回放控制条**：首手/上一手/下一手/末手逐手浏览，支持自动播放（慢/常/快三档）与进度滑块拖动，键盘 ←/→ 也可逐手翻阅；回放中棋盘只读，点「返回对局」无缝续战。
   - **逐手质量分析（本地引擎，离线可用）**：任意一手可算出评分、与引擎最佳点的匹配度、形成的棋形（活三/冲四/活四…）、防守价值，并自动定级为「引擎首选 / 好手 / 缓手 / 疑问手 / 关键漏防 / 错失杀招 / 一手致胜」等，同时给出更优替代点（点击即在棋盘上标出光环）。
   - **后续三手推演**：从任意局面出发，按双方最强应对推演下一步、下下一步、下下下一步的变化主线，并标注是否有一方连五致胜。
   - **大模型深度解读**：本地结论 + ASCII 文字棋盘一起交给 DeepSeek/Gemini 等大模型，产出教练口吻的四段棋评（本手定性/局势判断/后续变化/改进建议）。
   - **旧对局复盘**：战绩记录中的每一局都可一键载入完整棋谱，用同样的回放与分析工具复盘；分析结论与当前对局相互隔离、互不污染。
7. **☁️ 跨设备配置同步（手机不再需要重敲 API Key）**
   - **一次配置，多端可用**：浏览器的 `localStorage` 各设备互相独立，PC 上填好的大模型 Key 过去只能手机上再来一遍。现在在【⚙️ 设置 → 跨设备同步配置】点「🎲 新建」生成 10 位同步码 →「⬆️ 上传本机设置」，手机浏览器输入同一串码点「⬇️ 拉取并套用」即可。
   - **开机自动同步**：勾选后本机记住同步码，之后打开页面会自动比对时间戳，只在云端更新时才套用，本机改得更晚则保持不动（幂等，不会来回覆盖）。
   - **同步范围严格限定为设置**：大模型服务商 / Base URL / API Key / 模型 / 人设，以及难度、执子先后手、三三与四四禁手、禁手标记、音效。棋谱、战绩、复盘记录一律不上云。
   - **可随时收回**：「🗑 清除云端」立即删除；云端配置有效期 30 天，每次上传自动刷新。
   - **安全说明**：接口仅同源可用（不放开 CORS），载荷按字段白名单与类型逐项校验、限制 8KB，写读均有频控；同步码即钥匙（32 字符集 10 位，约 10^15 组合），请勿把截图或码值转发给他人。

### 方法一：通过 GitHub 自动构建部署（推荐，更新代码自动同步）

5. 点击 **Save and Deploy**。几秒钟内即可生成 `https://your-project.pages.dev` 访问链接！

### 方法三：网页端直接上传文件夹 (Direct Upload)
1. 登录 Cloudflare 后台，进入 **Workers & Pages** -> **Create application** -> **Pages** -> **Upload assets**。
2. 给项目命名（如 `my-gomoku`）。

### ⚠️ 关于「跨设备配置同步」的 KV 绑定
`/api/sync/<同步码>` 接口依赖一个 KV 命名空间（见 `functions/api/sync/[code].js`），部署方式不同，绑定方式也不同：

- **用 Wrangler 部署（方法二）**：会自动读取本仓库 `wrangler.toml` 中的绑定，无需额外操作。
- **后台直接上传（方法三）或连接 Git 部署**：不会读取 `wrangler.toml`，需在 **项目 → Settings → Functions → KV namespace bindings** 手动添加一条，**Variable name 必须填 `SETTINGS_KV`**，否则同步会返回「服务端未绑定 KV 命名空间」。

想换成自己账号下的命名空间，先创建再替换 id：
```bash
npx wrangler kv namespace create SETTINGS_KV
# 把输出的 id 填进 wrangler.toml 的 [[kv_namespaces]]
```

本地联调（无需部署即可测试同步接口与页面）：
```bash
npx wrangler pages dev . --port 8799 --kv SETTINGS_KV
# 浏览器访问 http://127.0.0.1:8799
```
> 提示：纯 `python -m http.server` 只能跑静态页面，不含 Functions，因此同步接口会返回 404；其余功能（含本地算法分析）不受影响。

> 另注：Cloudflare 的 Bot 防护可能按客户端指纹拦截非浏览器请求（返回 `error code: 1010`），用脚本自测接口时记得带上浏览器 User-Agent，真实浏览器访问不受影响。

## 📜 规则小知识：先手禁手

五子棋中，先行一方具有极大的进攻优势（先手必胜定式）。为保证公平竞技性，标准五子棋规则（Renju）规定：
- **三三禁手**：黑方（先手）一子落下若同时产生两个或两个以上的“活三”，则不可落子。
- **四四禁手**：黑方一子落下若同时产生两个或两个以上的“四”（活四与冲四都计入），同样不可落子。
- **长连禁手**：黑方一子落下形成 6 颗及以上连子，不可落子。
- **白方（后手）**没有上述任何禁手限制，并且白方连成 5 颗或以上均算获胜。
- 如果黑方一子同时连成“五连”和禁手，以“五连获胜”优先，不按禁手处理。

### ⚠️ 四三杀为什么不是禁手

黑棋要赢，只能靠「四三杀」：一子同时形成一个“四”和一个“活三”。这里有个极易踩的坑——
**某方向一旦构成“四”，该方向就不能再计入活三**，方向分类必须按优先级 **五 > 四 > 三**。

反例：黑棋横向形成 `●●●·●`（跳四，补空档即成五连），纵向同时形成跳活三。
正确判定是「四 + 活三 = 四三」，合法取胜；若把已成四的方向也计入活三，就会误判成三三禁手。

## 🆕 更新记录

### v1.1.3

- **「测试模型连接」升级为「模型体检」（重要）**：原按钮只发一条 `max_tokens: 10` 的「请回复一个字：好」，与真实对弈**没有共享任何代码**——所以它永远显示 1 秒内响应，却完全测不出对弈时的真实性能。这正是「连接测试 1 秒、对弈却要 5 分钟」这一错觉的来源。现改为两阶段探测：
  - **阶段一 · 握手**（12 秒超时）：判定网络连通、鉴权、模型名是否存在，并按 401/403/404/429/400 分别给出可操作提示；
  - **阶段二 · 真实负载**：复用对弈同一条路径（`buildPrompt` + `consumeChatStream` + 45s/180s 双超时），用真实棋局（优先当前盘面，不足 3 手时用内置中盘基准局面）实测 **首字节延迟 / 完整落子耗时 / 流式是否可用 / 是否推理型模型 / 输出能否解析出合法坐标**。
- 报告以多行体检形式呈现，按 ok / warn / fail 三色标记；探测期间实时显示「已等待 Ns · 接收 M 字」，慢模型也不会看起来像卡死。
- **探测与对弈行为一致**：体检里超时，对弈时同样会超时降级——不会出现「测试通过但对局翻车」。
- `parseMoveJson` 抽为共用函数，对弈与体检复用同一套容错解析。

### v1.1.2

- **大模型对弈改为流式输出（重要）**：此前 `getLLMMove` 是一次性请求，必须等服务端把 250 token 全部生成完才返回，界面只有一句「AI 正在精密计算中…」，无法区分「模型在思考」和「请求已卡死」。现改用 SSE 流式，状态栏实时显示「已用 Ns · 接收 M 字」，AI 气泡同步滚动显示模型输出片段。
- **新增双超时保护（重要）**：原 `getLLMMove` 没有任何超时控制（同文件的 `requestDeepAnalysis` 有 30 秒 `AbortController`，这里漏了），服务端不返回就会一直挂着，直到浏览器网络栈放弃（Chrome 约 5 分钟），期间棋盘被 `setLocked(true)` 锁死。现加双保险：**空闲超时 45 秒**（多久收不到数据算卡死；只要还在持续输出就不触发，避免掐断正常的长思考）+ **总超时 180 秒**（整轮硬上限）。超时后自动改由本地引擎代下，并用 toast 明确告知。
- **推理型模型兼容**：`deepseek-reasoner`、`gemini-2.5-pro`、带 thinking 的 qwen 等模型，思考链（`reasoning_content`）**不受 `max_tokens` 约束**——简单 prompt 秒回、复杂棋局却可能思考数分钟。这正是「连接测试 1 秒、对弈却要 5 分钟」的根因。现识别此类模型后不再传 `temperature`（部分服务商要求必须为 1.0，否则报 400），并优先展示思考链内容。
- **流式兼容兜底**：若服务端忽略 `stream` 参数、返回普通 JSON（部分 OneAPI 中转、自建 Ollama），自动按非流式解析，不会因本次改造而不可用。
- **请求中断**：对局结束或中途重开时，流式回调返回 `false` 通知上游中止请求，避免旧请求回写新对局界面。

### v1.1.1

- **修复双人同屏悔棋「先手变后手」（重要）**：双人模式下悔棋原先只撤销 1 手（对手的落子），回合随即交还给对手，当前玩家反而失去先手。现改为撤销**双方最近一轮**（对手 1 手 + 自己 1 手），回合回到当前该下的一方，与按钮提示及说明文案保持一致。人机模式行为不变（轮到玩家时撤 2 手，AI 回合撤 1 手）。

### v1.1.0

- **修复禁手误判（重要）**：`checkForbidden` 原先统计活三时未排除已经成“四”的方向，导致「四三杀」（如横向跳四 `●●●·●` + 纵向跳活三）被误判为三三禁手、黑棋无法落子取胜。现按方向优先级 **五 > 四 > 三** 判定，已成四的方向不再计入活三。

- 设置项新增 `checkDoubleFour`，旧版本 localStorage 配置会自动补默认值，无需手动清理。
